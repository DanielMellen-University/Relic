# Relic 1.0 checklist

1.0 is a toy that works: small programs run end to end, with the C/C++ host. This is milestone M6 in [PROJECT_PLAN.md](PROJECT_PLAN.md). Released as `v1.0.0` under the MIT license. One check, the human FizzBuzz test, is still open.

## Not in 1.0

Modules, imports, catchable errors, type hints, a bytecode VM, graphics, and self-hosting. These belonged to later phases. All have since landed. The desktop shell started in M11 now lives in M0N0LITH-2.

## Open design, after 1.0

All six are done, in the tree-walker, the VM and the self-hosted interpreter (see [LANGUAGE.md](LANGUAGE.md)):

- [x] Catchable errors: `try` / `catch err`, `fail(message)`
- [x] Separate `int` and `float`
- [x] `as` type hints on `let`, parameters and returns; `use path as name`
- [x] Private names: a leading `_` keeps a module name inside its file
- [x] UTF-8 strings that count characters; `\u{hex}` escapes
- [x] Final GC: reference counts plus a cycle collector, `gc()`

## Language

- [x] Numbers with `+ - * / %` and comparisons
- [x] Strings with joining and length
- [x] Bools with `and`, `or`, `not`
- [x] `none`
- [x] `let` variables and reassignment
- [x] Indentation blocks, with clear errors for bad indents and tabs
- [x] `if` / `else if` / `else`, `while`, `for ... in`, ranges, `break`, `next`
- [x] `fun` functions with arguments, `return`, closures and the one-line form
- [x] Lists: create, index, set, append, length
- [x] Maps: `{key: value}`, read and set by `.key` and `["key"]`
- [x] String interpolation with `{name}`
- [x] `print`

## Tools

- [x] `relic file.relic` runs a file
- [x] `relic` with no file starts a REPL
- [x] Errors show file, line and column

## Quality

- [x] Test suite of `.relic` programs with expected output
- [x] CI green on every push
- [x] README explains how to build and run
- [x] Every syntax error and runtime error has an error test (internal "should never happen" errors excepted)
- [x] License chosen and added (MIT)

## Acceptance

1.0 ships when every box above is ticked, CI is green on main, and a person who has not seen the code can write and run FizzBuzz using only the README. The README now has a "Relic in five minutes" section covering every piece FizzBuzz needs; this check still needs a real person.

- [ ] **Open:** a person writes and runs FizzBuzz using only the README

## Proof

- [x] A recursive function (factorial or Fibonacci)
