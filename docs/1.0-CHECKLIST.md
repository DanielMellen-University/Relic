# Relic 1.0 checklist

1.0 is a toy that works: small programs run end to end, with the C/C++ host. This is milestone M6 in [PROJECT_PLAN.md](PROJECT_PLAN.md).

## Not in 1.0

Modules, imports, catchable errors, type hints, a bytecode VM, graphics, and self-hosting. These belong to later phases.

## Language

- [ ] Numbers with `+ - * / %` and comparisons
- [ ] Strings with joining and length
- [ ] Bools with `and`, `or`, `not`
- [ ] `none`
- [ ] `let` variables and reassignment
- [ ] Indentation blocks, with clear errors for bad indents and tabs
- [ ] `if` / `else if` / `else`, `while`, `for ... in`, ranges, `break`, `next`
- [ ] `fun` functions with arguments, `return`, closures and the one-line form
- [ ] Lists: create, index, set, append, length
- [ ] Maps: `{key: value}`, read and set by `.key` and `["key"]`
- [ ] String interpolation with `{name}`
- [ ] `print`

## Tools

- [ ] `relic file.relic` runs a file
- [ ] `relic` with no file starts a REPL
- [ ] Errors show file, line and column

## Quality

- [ ] Test suite of `.relic` programs with expected output
- [ ] CI green on every push
- [ ] README explains how to build and run
- [ ] Every syntax error and runtime error has an error test
- [ ] License chosen and added

## Acceptance

1.0 ships when every box above is ticked, CI is green on main, and a person who has not seen the code can write and run FizzBuzz using only the README.

## Proof

- [ ] FizzBuzz
- [ ] A recursive function (factorial or Fibonacci)
- [ ] A small program that sorts a list
